# NURA

Speak-first language membership. Learn **English, Spanish, German, French, Dutch**. UI in TR / EN / ES / DE / FR / NL.

## Run

```bash
flutter pub get
flutter run -d chrome
# or web server
flutter run -d web-server --web-hostname 0.0.0.0 --web-port 8080
```

iOS / Android: open `ios/` in Xcode or `android/` in Android Studio after `flutter pub get`.

## Product locks

- Free speaking: **60 seconds / local day**
- Ads & AI books in **USD**
- Free speech is **on-device** (zero COGS). Cloud voice is Plus.
- Translate does not invent. Curriculum + travel lexicon only.
- Method: Hear → Shadow → Speak → Fix → SRS

See `docs/ECONOMICS.md`.
